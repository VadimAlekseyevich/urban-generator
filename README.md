# Urban Generator

Веб-сервис для ВКР по процедурной генерации городской застройки с учётом пространственных, инфраструктурных и демографических ограничений.

По подготовленной карте территории сервис должен продолжать существующие улицы, размещать жилые дома и школы, рассчитывать прирост населения и показывать дефицит доступных школьных мест. Первый выпуск рассчитан на локальную демонстрацию в браузере.

**Текущий этап — начало v0.1, задачи #1–2.** Работают стартовая страница Streamlit и модели территории и сценария. Загрузка карты, демотерритория, генерация и экспорт запланированы в следующих задачах. [Дизайн-документ и план семи версий до MVP](docs/DESIGN.md) содержит легенду TIFF и GeoTIFF, алгоритмы, стек, недельный календарь и контрольные примеры.

## Установка

Нужны Python 3.12 и [uv](https://docs.astral.sh/uv/getting-started/installation/). Получи рабочую копию и установи зависимости:

```bash
git clone https://github.com/VadimAlekseyevich/urban-generator.git
cd urban-generator
uv sync --frozen
```

Команда создаёт `.venv` и устанавливает зависимости из `uv.lock`, включая pytest. Версия Python задана в `.python-version`, поддерживаемый диапазон — в `pyproject.toml`. Для первой установки нужен доступ к сети. Если Python 3.12 отсутствует, uv может скачать его автоматически.

## Запуск

```bash
uv run streamlit run app.py
```

Открой <http://localhost:8501>. На странице появятся заголовок «Urban Generator» и сообщение «Приложение запущено». Сервер и приложение работают в одном локальном Python-процессе. Остановка — `Ctrl+C` в терминале.

## Проверка

```bash
uv run pytest -q
```

Smoke-тест выполняет страницу через Streamlit AppTest и проверяет отсутствие ошибок, заголовок и сообщение о запуске. В среду также входят Rasterio, NumPy, SciPy и Pillow для следующих задач.

## Модели вычислительного ядра

`urban/model.py` импортируется без запуска интерфейса. В нём определены общая легенда `ClassCode`, фиксированные коэффициенты из §3, `CoordinateMode`, `Terrain` и `Scenario`.

`Scenario()` задаёт демопараметры: 600 жителей, 3 этажа, шаг улиц 8 ячеек, одну школу на 80 мест, путь 400 м и seed 42. Диапазоны и единицы доступны через `dataclasses.fields(Scenario)` в `metadata` (`min`, `max`, `unit`). Счётчики и seed принимают целые числа; предельный путь допускает дробные метры. Некорректные значения вызывают `ValueError`.

`Terrain` хранит исходные `classes`, булеву `valid_mask` (True — внутри исследования), `pixel_size_m`, `coordinate_mode`, `crs`, `transform` и `input_sha256` — SHA-256 байтов входного файла. Массивы копируются и защищаются от записи. Маска объединяется с кодом 255, исключённые ячейки получают 255. В локальном режиме передаются `crs=None`, `transform=None`: модель строит привязку с началом (0, 0) в левом нижнем углу. Геопривязанный режим принимает Rasterio CRS и Affine и сохраняет их. Чтение файлов будет реализовано в задаче #4.
