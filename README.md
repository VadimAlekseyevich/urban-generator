# Urban Generator

Веб-сервис для ВКР по процедурной генерации городской застройки с учётом пространственных, инфраструктурных и демографических ограничений.

По подготовленной карте территории сервис должен продолжать существующие улицы, размещать жилые дома и школы, рассчитывать прирост населения и показывать дефицит доступных школьных мест. Первый выпуск рассчитан на локальную демонстрацию в браузере.

**Текущий этап — проектирование.** [Дизайн-документ и план семи версий до MVP](docs/DESIGN.md) содержит легенду TIFF и GeoTIFF, алгоритмы, стек, недельный календарь, контрольные примеры и сопоставление с НИР.

Первая задача — версия v0.1. Её результатом станет страница, на которой можно открыть демотерриторию, скачать её GeoTIFF и загрузить этот файл обратно с теми же классами и площадями.
