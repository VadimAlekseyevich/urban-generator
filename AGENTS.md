# Работа над Urban Generator

Проект ВКР: локальный сервис достройки города на карте классов TIFF/GeoTIFF,
оценки прироста населения и доступности школ. Спецификация — `docs/DESIGN.md`.
Общайся с пользователем по-русски.

## Выполнение задач

- Один запрос на разработку — одна GitHub issue, если пользователь не задал иной объём.
- Начинай новую задачу с актуального `main`, создай отдельную ветку.
- Прочитай карточку, указанный раздел спецификации, зависимости и текущий код.
- Реализуй задачу и выполни проверки из карточки. Основные команды:
  `uv sync --frozen`, `uv run pytest -q`, `uv run streamlit run app.py`.
- После завершения задачи и успешных автоматических проверок создай PR в `main`
  и сразу слей его без дополнительного подтверждения пользователя.
  Завершённые PR не оставляй в черновиках. Свяжи PR с issue через `Closes #N`.
- При проваленных проверках исправь причину до слияния. Не обходи обязательные
  проверки и ограничения GitHub. Непроведённые ручные проверки и ограничения среды
  явно укажи в PR и итоговом ответе.
- После слияния обнови локальный `main`; следующую задачу начинай от него.
- В конце сообщи результат, ссылку на влитый PR, итог проверок и что осталось
  непроверенным.

## Технические ограничения

Python 3.12, Streamlit, Rasterio, NumPy, SciPy, Pillow и pytest.
Приложение запускается локально одним процессом. Сохраняй простую архитектуру,
исходные объекты карты и воспроизводимость по seed. Вычислительное ядро должно
импортироваться без запуска интерфейса. Ограничения и алгоритмы сверяй с DESIGN.md.
