# Демотерритория

`demo.tif` — синтетическая карта для показа и контрольных проверок. Геопривязка условно размещает её в EPSG:32637 (WGS 84 / UTM zone 37N); карта не описывает реальную застройку.

Размер — 96×96 ячеек (960×960 м), один канал UInt8, шаг 10 м, NoData=255. Левый верхний угол имеет координаты (500000, 6200000) м. Столбцы направлены на восток, строки — на юг; поворота нет.

| Код | Содержание | Ячеек | Площадь, м² |
|---|---|---:|---:|
| 0 | Свободная земля | 8668 | 866800 |
| 1 | Река, запрет строительства | 384 | 38400 |
| 2 | Исходная улица | 112 | 11200 |
| 3 | Пять исходных домов 2×2 | 20 | 2000 |
| 255 | Два исключённых угловых участка | 32 | Исключены из площади исследования |

Река занимает столбцы 56–59 и все строки; нумерация здесь начинается с нуля. Мостов нет. Вся исходная застройка и единственная четырёхсвязная улица с перекрёстком находятся западнее реки. Восточный берег полностью свободен и не содержит дорог.

Из корня репозитория после установки зависимостей:

```bash
uv run python -m examples.create_demo
uv run pytest -q
```

Первая команда пересоздаёт `examples/demo.tif`. Необязательный позиционный аргумент задаёт другой выходной путь; его родительский каталог должен существовать.

Скрипт использует только фиксированные координаты и общую легенду из `urban.model`. Seed не меняет исходную карту: он относится к сценарию генерации. Тест запускает скрипт в отдельный временный файл и сравнивает с включённым GeoTIFF массив, маску, CRS и transform. Совпадение байтов TIFF между разными версиями GDAL не требуется.

Проверки также подтверждают разрыв между берегами, связность исходной улицы и предварительную пригодность для демопараметров seed 42: после исключения осей будущих улиц вдоль исходной дороги помещаются отдельная школьная ячейка и непересекающиеся дома 2×2, достаточные для цели 600 жителей. Размещение по пригодности, выбор школьного резерва и фактическое обслуживание спроса будут проверяться после реализации генератора.
