# Демографический профиль сценария (#55)

В форме застройки раскрой «Демографический профиль». Коэффициенты относятся
только к новым жителям. Это сценарные допущения; укажи источник данных или
заметку, описывающую выбранные значения.

| Поле | Исходное значение | Диапазон ввода |
|---|---:|---:|
| Площадь на человека | 30 м²/чел. | 5–200 м²/чел. |
| Полезная доля площади этажей | 80% | 5–100% |
| Доля школьников | 12% | 0–100% |
| Источник / заметка | Сценарные коэффициенты MVP | Непустой текст, до 1000 символов |

Диапазоны — ограничения модели, не нормативы и не статистика города.
Значения формы применяются только кнопкой «Сгенерировать». Ошибка ввода
не заменяет завершённый отчёт, ZIP и сравнение. Под картой показан профиль
выполненного расчёта; каждый вариант A/B сохраняет свой профиль и источник.

Для площади пятна A, этажности F, полезной доли u, площади на человека q
и доли школьников s:

```
N = floor(A × F × u / q + 0.5)
D = floor(N × s + 0.5)
```

Округление выполняется по каждому дому, половины округляются вверх.
Дом 20×20 м в 3 этажа при прежнем профиле даёт 32 жителя и спрос 4 места.
Демо даёт 19 домов, 608 жителей и спрос 76. При u=81,25%, q=30 и s=50%
то же пятно даёт 33 жителя (32,5 до округления) и спрос 17 (16,5).

Изменение только доли школьников не меняет геометрию домов и улиц, но
меняет спрос, выбор школ и распределение мест. При s=0 спрос отсутствует,
процент покрытия равен null, школы не открываются. Изменение u или q
меняет население дома и момент остановки по цели, поэтому число домов
может измениться. Если после округления дом вмещает 0 жителей, приложение
объясняет невозможность достижения цели этим профилем.

Через ядро:

```python
from urban.model import DemographicProfile, Scenario

profile = DemographicProfile(
    area_per_resident_m2=30,
    useful_area_fraction=0.8,
    schoolchild_fraction=0.25,
    source_note="Контрольный сценарий: 25% школьников",
)
scenario = Scenario(demographic_profile=profile)
```

В API доли заданы от 0 до 1, в форме — проценты. Профиль неизменяемый,
отклоняет неверные типы, NaN/бесконечность, выход за диапазон и пустой
источник. Старые вызовы Scenario без профиля получают прежние коэффициенты.

В `metrics.json.parameters.demographic_profile` сохраняются все коэффициенты
и заметка. `model_coefficients` содержит фактически применённые значения.
Профиль включён и в метаданные `project.geojson`. Независимая проверка
пересчитывает N и D по профилю конкретного результата; прежние числа с
новыми параметрами не принимаются как завершённый результат.

```bash
uv run --frozen pytest -q tests/test_demography.py
```

Контрольные проверки не доказывают пригодность коэффициентов для реального
населения: статистический источник для своего участка выбирает пользователь.
