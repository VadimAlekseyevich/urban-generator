# Производительность и чистая установка (issue #20)

## Повторение

Из корня свежего клона (Python 3.12, uv):

```sh
uv sync --frozen
uv run --frozen pytest -q
uv run --frozen python -m examples.run_benchmark --output-dir benchmark-results
```

После установки замер может выполняться без сети с `uv run --offline --frozen python -m examples.run_benchmark --output-dir benchmark-results`.
Результат — timings.csv (10 наблюдений) и benchmark.json (метаданные, метрики, медианы и параметры).
Сохранённые [исходные замеры](benchmarks/timings.csv) и [сводка](benchmarks/benchmark.json)
получены в [GitHub Actions, run 45860979529](https://github.com/VadimAlekseyevich/urban-generator/actions/runs/45860979529),
26.11.2026, коммит `e0f745afd1d551783d8f3f3858217168f9a0f41f`.
В чистом рабочем каталоге CI создана новая .venv командой uv sync --frozen;
установлены 42 пакета. Полный pytest: 329 passed in 8.87s.
Это не ноутбук защиты; наличие кэша uv не означает чистую загрузку всех пакетов из сети.

## Методика

Оба входа — одноканальные GeoTIFF, 10 м/пиксель, одна река без мостов и
незастроенный противоположный берег. Для 96×96 — examples/demo.tif,
цель 600, шаг улиц 8, бюджет 1. Для 256×256 — синтетический вариант той же схемы,
цель 20 000, шаг улиц 5, бюджет 3. Для обеих карт seed 42, 3 этажа,
80 мест в школе, максимальный путь 400 м.
Пятна исходных домов остаются 2×2. Хеши входов сохранены в JSON.

На каждый размер один прогрев и пять измеренных проходов. perf_counter измеряет
последовательные стадии. Генерация включает пригодность, дороги, резерв, дома,
школьный расчёт и проверку результата. Чтение из готовых байтов и экспорт
(включая повторную валидацию при экспорте) измеряются отдельно.
Создание тестового TIFF, чтение файла с диска и UI не входят в замер.
Медиана суммы стадий считается по каждому полному проходу, а не сложением медиан.
Метрики и размер ZIP совпадают с прогревом на всех повторах.

Обе медианы генерации ниже порогов 3 и 10 секунд соответственно в среде CI.
На 96×96 размещены 19 домов, 608 жителей; на 256×256 — 625 домов, 20 000 жителей,
три школы, 240 из 2500 мест спроса. Нарушения и несвязанные новые дороги равны нулю.
На большой карте наиболее дорогая стадия генерации — независимая валидация
(~27 мс из ~47 мс); экспорт также включает её повтор. Оснований менять алгоритм
по этим измерениям нет.

## Что остаётся проверить

На ноутбуке защиты выполнить те же три команды из свежего клона,
зафиксировать CPU, RAM, ОС, версии и сохранить новый benchmark.json и timings.csv.
Сравнить медианы generation_s с 3/10 с. Если порог превышен, проверить
разбивку стадий, затем профилировать самую дорогую. Отдельно проверить
первую установку, запуск UI и скачивание в браузере (#21).
Целевые пороги пока подтверждены только на CI, а не на ноутбуке.
Реальные карты и затраты браузера не измерены.
