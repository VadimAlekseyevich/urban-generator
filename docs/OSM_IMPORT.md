# Импорт локального OpenStreetMap PBF (v1.1, #45)

Импорт — отдельный шаг подготовки исходной карты. Генератор по-прежнему
принимает одноканальный GeoTIFF по §2–4 DESIGN.md, не читает региональный
PBF в Streamlit и не отправляет его в сеть. Дополнительный Pyosmium
подключается только к команде импорта; базовый uv.lock не изменён.
[Pyosmium](https://docs.osmcode.org/pyosmium/latest/) имеет колёса для Windows/Python 3.12.

## Windows PowerShell

Из корня urban-generator после `git pull origin main` и `uv sync --frozen`:

```powershell
$pbf = "C:\путь\к\central-fed-district-latest.osm.pbf"
uv run --frozen --with osmium==4.3.2 python -m examples.import_osm "$pbf" --lon 39.72 --lat 54.62 --size 256 --pixel-size 10 --output ryazan.tif
uv run streamlit run app.py
```

Подставить **фактический путь** к файлу (например, перетащить файл в PowerShell).
Долгота 39.72, широта 54.62 — пример центра окна, не утверждение о пригодности
конкретного квартала. Для другого участка изменить координаты центра.
Размер 256×256 при 10 м/пиксель — окно 2,56×2,56 км; при 5 м — 1,28×1,28 км.
Открыть «Свой TIFF», выбрать ryazan.tif, проверить карту, подтвердить легенду,
запустить генерацию. Файл ryazan.osm.json (имя от выходного TIFF) содержит
происхождение данных, число геометрий, площади в ячейках и привязку.
Существующие выходные файлы не перезаписываются.

Первый запуск uv с дополнительной зависимостью требует интернета для её
установки. Сам импорт работает локально. Весь региональный файл сканируется,
индекс координат узлов и сборщик полигонов могут занять несколько ГБ RAM;
время и пиковая память на 835 МБ ещё не измерены. На 32 ГБ RAM стоит
сначала попробовать исходник, при нехватке памяти предварительно вырезать
регион меньшего размера утилитой osmium extract или использовать другой
поддерживаемый индекс (--index sparse_mem_array). Индекс по умолчанию flex_mem.
Выходной TIFF мал; исходный PBF не хранить в Git. Если в окне нет доступной
исходной дороги, импорт выдаст ошибку. Выбрать другой центр.

## Правила классов, версия 1

- 0: ячейки без распознанного ограничения. Это **не** разрешение строительства.
- 1: известные запреты — вода и водотоки, железные дороги, леса, парки,
  поля, кладбища, промышленные/коммерческие и другие выбранные зоны,
  школы/социальные объекты и некоторые иные теги (см. urban/osm_import.py).
  Точечная школа защищает только свою ячейку; неизвестная граница не восстанавливается.
- 2: выбранные типы автомобильных дорог. Мосты, тоннели, непубличные и прочие
  highway консервативно защищаются кодом 1. Проект не строит полноценный
  пешеходный граф OSM, не моделирует развязки или ширины проезжей части.
- 3: контуры зданий и building:part, включая multipolygon.
- 255: NoData (объявлен, но прямоугольное окно заполнено классами 0–3).
  Наличие покрытия выгрузки и полнота OSM не установлены автоматически.

Пересечения: здания > запреты > дороги > 0. Растеризация all_touched
консервативно сохраняет тонкие объекты, но может разрывать дороги и увеличивать
их ширину. Локальная метрическая UTM по центру, квадратный пиксель без поворота.
Геометрии, пересекающие окно по bounding box, сохраняются; Rasterio ограничивает
их границами растра. Ошибки построения геометрий считаются по всему скану.
Подготовленный вход проверяет тот же read_terrain, что и интерфейс.

## Ограничения и лицензия

Исходные данные © OpenStreetMap contributors, https://www.openstreetmap.org/copyright
(ODbL). Атрибуция и SHA-256 PBF находятся в TIFF и JSON. При публикации карт
и производных данных сохранять атрибуцию и учитывать условия ODbL.
Экспорт MVP хранит хеш входного TIFF, не автоматически переносит OSM-метаданные;
при публикации сохранять рядом .osm.json и указание источника.

Нет данных кадастра, нормативных отступов, охранных зон, рельефа и свободных
мест существующих школ; незаполненные OSM ячейки нельзя принимать за юридически
доступную землю. Пользователь проверяет исходную карту. Алгоритм MVP,
размер участка, визуализация и школьная модель не изменены.

## Проверки

```bash
uv run --frozen pytest -q
uv run --frozen --with osmium==4.3.2 pytest -q tests/test_osm_import.py
```

Тест формирует реальный маленький PBF из синтетических объектов и проверяет
дороги, здание, парк, водный multipolygon с отверстием, точку школы,
геопривязку и сохранность исходных классов при генерации.
